概要

Jeremy Travel Analytics（以下「本ツール」）は、チャンネル所有者本人が自分の YouTube チャンネルの統計データを分析するためだけに使用する個人用ツールです。一般には提供していません。

取得する情報

本ツールは YouTube Data API と YouTube Analytics API を通じ、所有者本人が許可したチャンネルの動画情報と統計データ（再生数、視聴時間、収益の推計値など）を読み取り専用で取得します。

利用目的と共有

取得したデータは所有者本人のコンテンツ戦略の分析にのみ使用し、第三者への販売・共有は行いません。

アクセスの取り消し

アクセス権はいつでも Google アカウントの権限設定 から取り消せます。

English

Jeremy Travel Analytics is a private tool used only by the channel owner. It reads, with read-only access, video metadata and analytics for the owner's own YouTube channel via the YouTube Data API and YouTube Analytics API. Data is used solely for the owner's content analysis and is never sold or shared with third parties. Access can be revoked at any time at Google Account permissions. This tool uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.
